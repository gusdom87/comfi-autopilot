# Jev: Graduated Autonomy for Guest-Message Triage

One-line pitch: Guest messages get triaged by urgency, and the system only acts on its own as far as its confidence earns, with a human approving everything else.

Built Oct 26 to Nov 4, 2026 for the Meta Global AI Developer Hackathon (Indie track).

Background note: the operator ran a pre-event guest-message triage pilot and hand-labeled a dataset before the hackathon. That pilot and dataset are background and baseline only. They are not hackathon work, and nothing in this repo presents them as built during the event. Everything demoed from this repo is built during Oct 26 to Nov 4, 2026.
